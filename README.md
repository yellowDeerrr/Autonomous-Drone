
# Autonomous Drone

An autonomous drone system built using PX4, ROS 2, Gazebo and Python.

## Technology stack

- Ubuntu 24.04
- ROS 2 Jazzy
- PX4 Autopilot
- Gazebo Harmonic
- Micro XRCE-DDS
- Python
- YOLO / Computer Vision

## Project structure

- `src/` - ROS 2 packages
- `models/` - AI model weights
- `datasets/` - Training and validation datasets
- `config/` - Configuration files
- `scripts/` - Utility scripts
- `docs/` - Project documentation
